# App icon sources

The Money Scribe launcher icon, drawn as SVG on a 108 × 108 canvas (Android
adaptive icon layout, foreground inside the 66 × 66 safe zone). The staging app
(`staging/`) has the same icon with an amber badge, so both apps can be told apart
on one phone: a dot at the lower right on Android and a diagonal band across the
top-right corner on the square icon.

| File | Use |
| --- | --- |
| `ic_launcher_background.svg` / `.png` | Android adaptive icon background layer |
| `ic_launcher_foreground.svg` / `.png` | Android adaptive icon foreground layer |
| `ic_launcher_monochrome.svg` / `.png` | Android 13+ themed icon layer |
| `ios_icon_1024.svg` / `.png` | iOS icon, web icons and the legacy Android icon |
| `staging/` | The same four files for the staging app |

The SVG files are the sources. The PNG files are what `flutter_launcher_icons`
reads: 432 × 432 px for the Android layers (108 dp at xxxhdpi) and 1024 × 1024 px
for the square icon. They are not bundled in the app.

To change an icon, edit the SVG files, export the PNG files at the sizes above,
then regenerate the icons. The tool reads one configuration file per flavor,
`flutter_launcher_icons-production.yaml` and `flutter_launcher_icons-staging.yaml`,
and writes `android/app/src/production/res` and `android/app/src/staging/res`; the
production file also writes the web icons:

```bash
dart run flutter_launcher_icons
```

The tool removes the final newline of `web/manifest.json`; add it back after every run
(`printf '\n' >> web/manifest.json`), because CI rejects a file without one.

The iOS icons are not generated by this tool for now. They were generated once from
`ios_icon_1024.png` (`ios/Runner/Assets.xcassets/AppIcon.appiconset`). The tool
rewrites an iOS project setting incorrectly and adds legacy icon sizes, so iOS icons
are set up with the iOS flavors, in Xcode on a Mac.
